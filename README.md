## ফোন/কম্পিউটার দুই জায়গাতেই কাজ করে
- ফোনে নিচে মেনু বার, কম্পিউটারে বাঁদিকে সাইডবার।
- ⚙ (ফোনে) চেপে "AI Scan API Key" আর "Claude API Key" বসান:
  - AI Scan API Key -> ছবি/লেখা থেকে খাবার স্ক্যান
  - Claude API Key -> AI ডায়েটিশিয়ান চ্যাট (console.anthropic.com থেকে key)
- key গুলো শুধু আপনার ব্রাউজারে সেভ থাকে, কোডে লেখা নেই।
- নতুন key কখনো index.html-এ নিজে লিখবেন না, কারণ সাইট পাবলিক।
